# mnr-client

`mnr-client`: the embeddable client library for wallets and backends. Verifies what a relayer returns and, later, checks agreement across relayers.

Part of [mnr — an RPC network for Monero](https://mnr.network). This crate
holds the name; the code lands as the plan in the repository reaches it.
