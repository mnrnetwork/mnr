# mnr-core

Wire types, hashing, verification rules, method policy and header chain for
[mnr — an RPC network for Monero](https://mnr.network). Pure functions over
bytes, no I/O, fuzzed and tested against real mainnet blocks. Wrap it in a
wallet or a relayer to check what a Monero node returns instead of trusting it.
